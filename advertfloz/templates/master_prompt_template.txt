CAMPAIGN CSV RULES
- All `enabled` values must be exact lowercase `false`; the user activates after review.
- `platforms` must be `facebook`, `instagram` or `facebook;instagram`.
- `scheduled_at` is `YYYY-MM-DDTHH:MM:SS` local wall time; timezone is an IANA zone, e.g. `Asia/Kolkata`. Do not use `IST`. Flag daylight-saving ambiguity/nonexistent time.
- `image_id` integer matches post ordinal.
- `caption` is required fallback; make `facebook_caption` and `instagram_caption` platform-specific. Include all intended hashtags in the effective caption.
- Instagram feed copy should use “link in bio” where appropriate; don't say the feed-caption URL is clickable.
- `destination_url` must be blank or a verified HTTPS route. Never invent product routes. UTM fields/values must not contain personal data.
- `ai_disclosure_status` default is `not_reviewed`; do not automatically mark `not_required`.
- `grace_minutes` blank unless an explicit bounded value is provided.
- Use RFC 4180 quoting and UTF-8; preserve Tamil, emoji, commas, quotes and multiline captions.
- `schema_version` goes in `campaign_manifest.json`, not the CSV row.
