### Complete standalone image prompt

Write a prompt that can be copied into an image generator without any previous context. Include subject, composition, palette, size, mobile readability, a clear manual typography zone, prompt not to render text/logos, negative rules and product-claim accuracy safeguards. Never write “same as above”.

### Negative prompt / avoid

No generated text, fake UI, watermark, fabricated statistics/testimonials, stereotypes, clutter or repeated template.
